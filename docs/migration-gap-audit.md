# 원본 따라오개 대비 마이그레이션 현황 · 2026-10-11

이 문서는 원본 소스 기준선, [원본 README 화면](https://github.com/nbc-final-team2/ddaraogae), 현재 양 플랫폼 제품 화면과 자동 검사, 전체 티켓 계획을 대조한 **현재 사실**이다. 화면 단위의 일치·차이는 [화면별 패리티 표](ui-parity.md), 이식 범위의 결정은 [ADR-013](adr/013-original-ui-port-scope.md)에 있다. 아래의 `구현`은 코드가 있다는 뜻이고 `확인`은 해당 환경에서 실제 실행했다는 뜻이다. 모든 화면 확인은 로컬 에뮬레이터/Simulator 기준이며 실기기·스토어 배포가 아니다.

## 화면 기대치

| 화면 | 이번 제품 빌드 | 아직 원본과 다른 점 |
|---|---|---|
| 홈 | 원본 레이아웃(32sp 제목, "N 시간 전", 반려견 원형, 7일 그래프, 도장 달성률, 날씨 카드)을 이식했고 그래프·시간·도장은 **로컬 이력에서 계산**한다. | 날씨·미세먼지는 데이터 공급자가 없어 "연결 전" 안내만 나온다. 반려견은 1마리다(원본은 여러 마리). |

| 마이페이지 | 원본 행·구분선·섹션을 이식했다. 반려견 정보와 알림 화면으로 이동한다. | 로그아웃·회원탈퇴·약관·개인정보 처리 행은 계정이 없어 "연결 전" 안내만 한다. 약관 본문은 원본 팀의 법적 문서라 복제하지 않았다. |

| 글꼴 | 시스템 글꼴을 쓴다. | 원본은 SF Pro를 쓰지만 재배포 조건과 한글 글리프 부재 때문에 넣지 않았다. |

`docs/evidence/M05/`의 시나리오 캡처에는 `개발용 예시 데이터 · ready` 같은 시험 배너가 나온다. **일반 제품 빌드에는 이 배너가 없다.** 시나리오 앱은 별도 Gradle 속성/Swift 조건으로만 만들어지고 release에서는 차단된다.

## 남은 작업 우선순위와 담당

| 우선 | 기능·상태 | 다음 기술 작업(에이전트) | 사용자에게 필요한 것 |
|---|---|---|---|
| P1 | **실제 지도**: Android Naver Map, iOS MapKit 모두 미구현 | `MapBackdrop`/`RouteMap` 한 지점에 지도 어댑터를 꽂고 저장된 위경도로 실제 경로·현재 위치·줌을 양쪽에서 검사 | NAVER CLOUD PLATFORM Maps 애플리케이션(Dynamic Map)과 패키지 ID `dev.ddaraogae.app` 등록, 새 Client ID. 이용 조건·과금은 본인 계정에서 확인. **원본의 기존 키는 재사용하지 않음** |
| P1 | **제품 인증/OAuth**: 일반 앱은 아직 `local-preview`, 로그인 UI는 시나리오 전용 | 전달 준비(클라우드·서명) 전체 검증을 통과한 뒤 인증 착수 정책대로 이메일 가입/인증·Google 로그인, A→B 계정 격리 | 새 Firebase 프로젝트에서 Google 제공업체 활성화, Android SHA-1 등록과 갱신된 `google-services.json`, iOS `REVERSED_CLIENT_ID` URL scheme |
| P1 | **서명·기기·TestFlight**: unsigned archive까지 확인, signed 설치·TestFlight 미확인 | 최종 SHA에서 서명 산출물 검증, 실제 기기 설치→산책·재실행 회귀 | Android 실기기, Apple 팀·App Store Connect 계약·앱 레코드·테스터 (계정 소유자가 직접 결정) |
| P1 | **여러 마리·사진·클라우드 동기화** | 반려견 ID 기반 산책 연결, 여러 마리 선택, 사진 실패 복구, 동일 UID 두 기기 조회 | Firebase Storage 과금제 승격 여부 또는 대체 저장소 선택 |
| P1 | **백그라운드 위치** | Android foreground service/알림, iOS background mode·정책, 실기기 장거리 테스트 | 실기기·OS 권한 선택과 현장 테스트 |
| P2 | **날씨·미세먼지·주변 장소·알림 예약** | 공급자 API 연결, 로컬 알림 예약과 권한 | 새 계정/키·할당량/비용 선택, 기기의 알림 권한 |
| P2 | **전체 품질/배포**: 접근성 스크린리더·성능·최소 OS·실기기 미검증 | 스크린리더/작은 화면, DB 이전, UI 스냅샷, CI에서 실제 UI 검사 | 최종 APK/TestFlight 설치와 반복 수정의 실기기 피드백 |

이전의 "홈·산책·기록 일부만 이식" 상태는 해소됐다. 남은 것은 위 표의 **기능 연결**이며 UI를 양보한 항목은 없다. P1/P2를 완료로 표시하지 않는다. 인증은 사용자가 확정한 "전달 준비 전체 최신 검증 후 인증 착수" 규칙을 유지한다.
